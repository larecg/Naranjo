Select any text on any webpage, right-click, and process it with your AI of choice — locally or in the cloud.

Add to Chrome — it's free
How it works

Select text on any webpage → right-click to open the context menu → pick an AI action. Or press Alt+Shift+Q to open the quick menu overlay, type a one-time prompt, and get a streaming response instantly.

Features
📄

Context menu on any text

Right-click selected text on any webpage to run your custom AI contexts instantly.

⚡

Quick menu overlay

Press Alt+Shift+Q for a floating overlay. Type a one-time prompt or pick a saved context without opening the popup.

🔠

Streaming responses

See the AI response token-by-token in real time, directly in the extension popup.

🌟

Per-context model override

Assign a specific provider and model to each context — use Gemini for translation, Claude for editing, Ollama for drafts.

📋

Task history

Every AI operation is saved with its full input, output, and model — searchable anytime.

🌐

English & Spanish

Full interface localization for English and Spanish, with system, light, and dark theme support.

Supported providers
Ollama (local & cloud) OpenAI Google Gemini Anthropic Claude Mistral AI xAI Grok DeepSeek

Local providers run entirely on your machine — no data leaves your browser.
